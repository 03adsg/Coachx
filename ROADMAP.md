# COACHX Roadmap

## Phase 1

- Establish the app shell and shared design tokens.
- Implement the primary Stitch-backed routes.
- Keep the mock data layer isolated from UI.
- Add reusable GSAP motion presets.
- Preserve mobile-first iPhone behavior.

## Phase 1 status

- App shell implemented.
- Today, Calendar, Day Detail, Progress, and Profile routes implemented.
- Motion layer added.
- Local fixtures added.

## Next phase candidates

- Expand shared components only where repeated by active screens.
- Connect Supabase behind the existing data interfaces.
- Add further Stitch screens only when they are explicitly in scope.
